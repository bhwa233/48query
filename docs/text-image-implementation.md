# 图文采集实施记录

2026-10-19，用户确认实施图文评审方案的全部候选来源，图片上传沿用 galaxy-spider 图库逻辑。

## 已实现的代码

- 移除 Pocket48 录播请求及批次依赖；ingest 拒绝非空录播列表，保留历史表和只读 API。原录播页面重定向到消息页。
- 接入房间、相册、精华、公开动态、动态图片、口袋微博分享与房间动态分享七类来源；只接受能核对身份的成员内容，保留实际作者与来源房间。
- 支持文字、图片／表情、公开回复／礼物回复／文字翻牌，结构化保存问答和附件；语音／视频只留占位，不下载、不转写。
- 图片使用 `https://gallery233.pages.dev/upload`，与 galaxy-spider 相同的 multipart 协议；上传缓存、失败重试与文字入库分离，保留原始图片格式。
- 每来源独立增量和历史游标，分片最后一片提交来源检查点。大整数 ID 在解析时保留字符串。
- 真实 API 驱动首页、成员页、动态成员详情、消息检索、图片页；不再以演示内容替代线上空数据。支持成员／类型／来源／日期筛选、问答检索、图片查看和来源状态。
